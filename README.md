# DIY-Audio-Mixer
Audio Mixer PCB and Software 
A simple audio mixer. Uses 4 60mm slide potentiometers and an arduino nano v3. Application uses PyQt5, currently limited to linux OS using wpctl to control application volumes. I am currently developing a V2 board that will include mute buttons, some LEDs. Some updates will also be coming for the application. Currently, it's very rough.
